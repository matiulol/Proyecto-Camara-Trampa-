# Camara Trampa Inteligente

Proyecto escolar 2026 para una camara trampa inteligente de reserva natural.

La etapa 1 implementa:

- Backend FastAPI.
- Conexion con MongoDB usando exclusivamente `Ani_cam`.
- Login basico con `usuarios`.
- CRUD basico de `camaras`.
- Listado, alta y consulta de `eventos`.
- App de escritorio PySide6 con login y dashboard.

Documentacion detallada: `docs/DOCUMENTACION_ETAPA_1.txt`.
